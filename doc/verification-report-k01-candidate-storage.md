# Verifikasi handoff penyimpanan kandidat K01

Dokumen ini mencatat workflow yang membaca EXTRACT dari checkpoint terverifikasi, membuat kandidat dari rencana scope exact, dan menyimpan artefak beserta dependency evidence. Ini laporan baru untuk handoff Go/PostgreSQL; [laporan kandidat sebelumnya](verification-report-k01-candidate-handoff.md) tetap mencatat kontrak/fixture domain pada tahap terdahulu.

Baseline sebelum perubahan `123302416d4fdd2f1e262ebf163ddf18ef5b0b7f`, diuji pada 2026-09-24 dengan Go 1.26.8 windows/amd64 dan PostgreSQL 18.0 disposable (`regulagraph_k01i`). Input tes mencakup checkpoint EXTRACT sukses, source artifact berhash, claim RESOLVE dengan lease/fence, rencana lookup legal eksplisit, serta alias registry positif dan kosong. Expected: dua pembacaan revision terikat fence mengapit satu lookup batch; perubahan revision sebelum penyimpanan menghasilkan `ErrCandidateViewChanged` tanpa `Put`; hasil stabil ditulis sebagai artefak content-addressed, terdaftar bersama fingerprint sumber serta revision scope positif/negatif.

Tes integrasi `TestSemanticRegistryAgainstPostgres` memeriksa ref yang terdaftar, byte yang lolos `ReadVerified`, dan baris `artifact_dependencies` untuk source fingerprint serta lookup kosong. `TestCandidateRevisionRaceRetriesBeforeArtifactWrite` memeriksa perubahan revision pada dua posisi tanpa menulis artefak. Validator domain juga menolak ID batch/canonical/alias yang bertabrakan dengan EXTRACT, source ref, atau mention. `go test ./... -count=1` dengan DSN PostgreSQL disposable: **PASS**, exit 0; log mentah `artifacts/verification/k01-candidate-storage-20260924/go-test-all.log`, SHA-256 `4bd16bbd0feab288ff1a7ec493198fd37c758d2069410ceca929d0f5a6eab728`. `go vet ./...`: **PASS**, exit 0; log `go-vet.log` mencatat stdout/stderr kosong dan exit code. `git diff --check`: **PASS**, exit 0. Reviewer independen melakukan review baca-saja dan tes Go tanpa DSN: **PASS terbatas**, tanpa blocker lokal; ia tidak menjalankan PostgreSQL sendiri.

Pemilihan scope/normalisasi legal dan proposal LINK/DEFER masih menjadi input dari producer yang belum tersambung; handoff ini tidak menebak canonical identity dari surface string. Perubahan registry setelah pemeriksaan akhir dapat meninggalkan artefak immutable yang tidak dipakai; writer masih menolak kandidat stale sebelum CAS. Review terautentikasi, dispatch stage, graph assembly, gold false merge/split, serta benchmark required kualitas, p95/p99, throughput, dan resource tetap **NOT_MEASURED/BLOCKED** sesuai prasyarat. Fixture ini tidak membuktikan K01 atau release end-to-end selesai.
