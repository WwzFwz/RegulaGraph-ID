# Verifikasi terminal replan RESOLVE K01

Dokumen ini membuktikan transisi job ketika intent RESOLVE immutable kehilangan kecocokan registry atau review. Cakupannya adalah status retry/cancellation/fence setelah konflik, bukan producer kandidat, penjadwalan job pengganti, maupun kualitas resolusi hukum.

Baseline sebelum perubahan `938cb2fbc5b081f1e412d9551d13a64305c0120d`, diuji pada 2026-09-24 dengan Go 1.26.8 windows/amd64 dan PostgreSQL 18.0 disposable (`regulagraph_k01i`). Fixture `TestSemanticRegistryAgainstPostgres` memakai EXTRACT/kandidat/review berhash, concurrent writer yang menaikkan revision, dan job RESOLVE kedua dengan candidate revision lama. Expected: intent tercatat sebelum CAS, writer menolak revision lama, job berubah menjadi `FAILED`, tanpa receipt/output palsu. Review dicabut atau berubah juga perlu replan; review yang belum tersimpan tetap konflik retryable agar producer dapat menyelesaikannya. `TestStaleResolutionOnlySignalsReplanAfterOwnTerminalFailure` memeriksa bahwa status `CANCELLED` dan lease yang kalah tidak memberi sinyal membuat job baru.

`go test ./... -count=1` dengan DSN database disposable: **PASS**, exit 0; log mentah `artifacts/verification/k01-resolve-replan-20260924/go-test-all.log`, SHA-256 `eee9fe15cf8a07b65a1aca2f5670ef6451d107ce5e77d816d6e377d1da1cf976`. `go vet ./...`: **PASS**, exit 0; log `go-vet.log` mencatat stdout/stderr kosong dan exit code. `git diff --check`: **PASS**, exit 0. Reviewer independen membaca diff dan menjalankan tes unit tiga paket tanpa DSN: **PASS terbatas** untuk klasifikasi review, cancellation, dan stale lease; ia tidak menjalankan PostgreSQL sendiri.

Masih terbuka: producer kandidat/proposal dan autentikasi reviewer produksi; job pengganti otomatis setelah `FAILED`; gold false merge/split dan benchmark required kualitas, p95/p99, throughput, dan resource. Gate tersebut **NOT_MEASURED/BLOCKED** sampai input, model, hardware, dan workload referensi siap. Tes fixture tidak menyatakan K01 atau release Hybrid GraphRAG selesai.
