# src/ingestion/src/worker

Boundary transport gRPC dan orkestrasi proses batch Rust. Folder ini menerima message C01, memvalidasi deadline serta attempt/fence, menjalankan transformasi melalui processor terbatas, dan hanya mengembalikan referensi artefak immutable. Go tetap memiliki status durable, retry policy, dan publication.

Anak folder tidak boleh menambahkan schema transport sendiri atau melakukan publication backend. Konversi Tonic dan rust-protobuf harus melalui byte Protobuf dari schema yang sama. Proses besar berjalan per batch, dibatasi ukuran pesan dan concurrency, serta memeriksa cancellation di antara item. Perubahan kontrak harus dimulai dari `src/contracts/proto`.

Ukur waktu antre, latency p50/p95/p99, throughput dokumen/byte, peak RSS, cancellation lag, serta retry/dedup. Target tetap berasal dari `configs/benchmark-targets.yaml` dan berstatus **REQUIRED_UNMEASURED** sampai benchmark corpus resmi dijalankan.

Saat ini transport ProcessBatch/GetStatus/Cancel dan processor tahap PARSE/STRUCTURE/CHUNK/EXTRACT tersedia. Registry lokal mengikat satu `job_id` pada corpus, auth scope, attempt, fence, dan fingerprint request lengkap; retry identik mengulang hasil terminal tanpa eksekusi, sedangkan payload berbeda, attempt/fence mundur, atau scope berbeda ditolak. Eksekusi tetap dimiliki task worker ketika caller terputus. Cancellation dan deadline dapat mengeluarkan job yang masih antre, dan deadline absolut diperiksa lagi ketika hasil dikomit ke registry. Registry ini tetap sementara dan dapat dievikt; fencing serta recovery durable tetap milik Go.

Processor PARSE memverifikasi path, ukuran, MIME `application/pdf`, dan SHA-256 setiap descriptor sebelum deduplikasi isi. Default satu batch dibatasi 256 source, 2 GiB input terdeklarasi, 100.000 halaman agregat, dan 50.000 halaman per dokumen, selain batas record/reference assembler. Mirror dengan hash sama tetap dicatat sebagai dependency terpisah tetapi hanya diparse sekali. Source observation dipertahankan di `DocumentBatch`; corpus, ID, dan optional source-blob reference diperiksa agar metadata tidak dapat ditempelkan pada bytes di luar request. Producer manifest output berasal dari binary/config parser aktual, termasuk hash library PDFium, bukan identitas yang diklaim caller. Respons membawa checkpoint PARSE yang mengikat ID, hash `DocumentBatch`, dan terminal outcome yang sama dengan completion response; service dan client Go menolaknya bila binding berubah atau outcome tidak cocok. Batch dengan halaman yang memerlukan OCR/review tetap dipersist sebagai bukti parsial dan dikembalikan dengan completion `FAILED`; batch tersebut tidak boleh dipublikasikan sebagai lengkap.

Processor STRUCTURE menerima tepat satu `DocumentBatch` PARSE, membaca raw/normalized/mapping secara content-addressed, memverifikasi normalizer manifest dan reproduksi mapping, lalu menghasilkan hierarchy tanpa ID hukum sintetis. CHUNK menerima tepat satu batch BIND lengkap, menolak binding version yang hilang/asing/ambigu sebelum tokenisasi, memverifikasi rekonstruksi struktur, membatasi byte dan token, memasang parent refs, serta mempertahankan dependency registry. EXTRACT menerima tepat satu batch CHUNK, memanggil Semantic Gateway dalam sub-batch berbatas, mengagregasi error per item, memvalidasi proposal, dan menyimpan `ExtractionBatch` immutable. Resolution, graph assembly, dan indexing masih ditolak. Cancellation diperiksa antar-source, antar-text-artifact, dan antar-sub-batch; satu pemanggilan PDFium yang sedang berjalan belum dapat diputus secara aman di tengah file.

Jalankan `cargo run -p regulagraph-ingestion --bin regulagraph-worker` setelah mengisi `REGULAGRAPH_WORKER_ARTIFACT_ROOT`, `REGULAGRAPH_WORKER_PDFIUM_LIBRARY`, `REGULAGRAPH_WORKER_PDFIUM_SHA256`, `REGULAGRAPH_WORKER_PDFIUM_VERSION`, `REGULAGRAPH_WORKER_TOKENIZER_JSON`, dan pin `REGULAGRAPH_WORKER_TOKENIZER_SHA256`. Loader membatasi file 128 MiB, memverifikasi hash sebelum decode, serta mematikan truncation/padding agar token cap menghitung seluruh teks. Listener default adalah `127.0.0.1:50051`; message maksimum, ukuran artefak, concurrency, dan kapasitas registry dapat diatur melalui variabel pada `.env.example`. Binary menolak bind non-loopback sampai TLS termination tersedia.
